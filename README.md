# WinBosk — Windows 桌面栅栏整理器

WinBosk 是一款 Windows 桌面图标整理工具，使用 Rust 编写，支持 Windows 10 / 11。它把散落的桌面图标按你的习惯分组收纳进「栅栏」，让桌面保持整洁、找东西更快。

## 它能帮你做什么

- **栅栏收纳**：桌面图标按组归类，支持网格 / 列表两种布局、透明玻璃卡片；可框选多选、拖拽移动 / 缩放、磁吸对齐、就地重命名。
- **控制中心**：一个单页面板统一管理所有栅栏——布局、图标大小、背景风格（玻璃 / 描边 / 纯色）、色调一键调整，实时生效并持久化。关闭后完全隐藏，不占地方。
  - 入口：`Ctrl+Alt+T`、托盘图标左键单击、或托盘右键菜单「显示 WinBosk 控制中心」。
  - 标题栏「切换桌面」按钮：在栅栏接管与原始桌面之间一键切换。
- **就地重命名**：栅栏 / 图标重命名直接在桌面上绘制与编辑，无需弹窗。
- **丝滑动效**：拖动 / 缩放跟手（过冲回弹）、面板开合淡入淡出、图标悬停放大 + 柔光。
- **安全接管桌面**：低风险接管桌面 `WorkerW` / `DefView`，不干扰 Wallpaper Engine 等动态壁纸；任何退出路径都会自动恢复桌面图标。
- **轻量省电**：空闲时几乎不占用 CPU，动画结束后立即停止渲染。

## 快速开始

1. 获取程序：发布后可通过 winget 或安装包安装（即将提供）；或从源码构建，见文末「开发者」一节。
2. 启动 `winbosk.exe`，桌面图标即被收纳进栅栏。
3. 按 `Ctrl+Alt+T` 打开控制中心，新建 / 整理栅栏。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl+Alt+T` | 打开 / 关闭控制中心 |
| `Ctrl+Shift+F10` | 全局退出（恢复桌面图标） |
| 控制中心「切换桌面」 | 栅栏 ⇄ 原始桌面一键切换 |
| 托盘图标右键 | 控制中心菜单（整理 / 显示控制中心 / 退出） |
| 托盘图标左键单击 | 打开 / 关闭控制中心 |
| 双击栅栏内图标 | 打开对应项（多选时全部打开） |
| `Ctrl` + 单击图标 | 不连续多选 |
| 空白处拖拽 | 框选多选 |
| 标题栏拖拽 / 边缘缩放 | 移动 / 调整栅栏、控制台 |

## 注意事项

- **不要强行结束进程**：退出请使用 `Ctrl+Shift+F10` 或控制中心「退出」。切勿用任务管理器、`taskkill /F`、`Stop-Process -Force` 等方式硬杀 `winbosk.exe`——这会跳过当次的图标恢复逻辑。不过程序具备**重启自愈**能力，重新打开 `winbosk.exe` 即可自动复位桌面图标，不会造成永久损坏；正常退出只是为了避免图标短暂错位。
- **单实例运行**：同一时间只能有一个 WinBosk 在运行。
- 首次接管桌面后，原桌面图标由 WinBosk 管理；正常退出即还原为原始桌面。

## 开发者

技术栈：Rust（MSVC 工具链）+ Windows UI Composition / Direct2D / DirectWrite 合成渲染；桌面接管基于 Win32 / COM（`IShellFolder`、WorkerW 探测等）；背景模糊走 DWM GPU 实时 BackdropBlur（无截图、无 CPU 高斯）。

构建：

```bash
cargo build --release                   # 产物 target\release\winbosk.exe，双击无控制台窗口
cargo test --workspace                  # 运行测试
cargo clippy --workspace -- -D warnings # 静态检查
cargo fmt --all -- --check             # 格式检查
```

开发迭代推荐使用 `dev-fast` profile（改一行约 14s 重编、无控制台窗口）。完整架构、分层依赖、CI 门禁与发布流程请查阅 [`AGENTS.md`](AGENTS.md)。
