WinBosk UX Mockups

按行业常见范式产出的 8 个独立 mockup，覆盖控制中心、桌面 overlay、命令面板、引导、HUD 与整理仪表盘。 每个文件自包含（单 HTML，无外部依赖），可直接在浏览器打开对比结构与视觉方向。

01

Fluent 设置风格

Windows 11 原生设置范式：左侧分区 + 卡片行 + 开关/分段控件。最「系统原生」、最低学习成本。

控制中心LightSettings
02

Linear 深色极简

键盘优先的工单式列表：面包屑、计数徽标、属性行。强调密度与快捷操作，适合高频用户。

控制中心DarkKeyboard-first
03

命令面板 / Palette

Raycast / Spotlight 式全局动作入口，浮在桌面之上。把「新建、整理、退出」收敛为一次键入。

桌面唤起OverlayPower user
04

桌面栅栏 Overlay

产品主场景：多栅栏玻璃卡片 + 折叠侧栏 + 自由区，展示磁吸、悬停与穿透的视觉目标。

主界面Glass场景图
05

侧栏检查器

Figma / IDE 式三栏：图层树 + 画布选中 + 属性检查器。把布局、存储模式、路径做成可编辑表单。

编辑模式InspectorPro
06

首次运行引导

四步向导：接管策略 → 安全边界 → 快捷键 → 就绪。把 IconGuard / 单实例等硬约束翻译成用户语言。

OnboardingWizardTrust
07

紧凑浮动 HUD

底部胶囊工具条：面板 / 整理 / 折叠 / 桌面一排触达，展开二级菜单。始终可见但不占版面。

HUD浮层Minimal
08

整理仪表盘

指标 + 看板 + 未分组收件区：处理「17 个自由项」的专项工作流，支持拖放归组与一键整理。
