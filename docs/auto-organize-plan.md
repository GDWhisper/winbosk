# Sylva 桌面整理器：交互与分类体验重构计划

## 1. 背景与核心痛点

当前交互存在两项违背用户心智模型的设计：
1. **「＋ 添加栅栏」强制弹窗选目录**：把“高级的目录镜像（Folder Portal）”作为创建栅栏的前置强约束，导致用户只是想要一个普通的桌面收纳盒，却被强迫在文件系统中挑文件夹；
2. **「一键整理」缺乏智能开箱即用能力**：用户必须先手动建好几个栅栏、再分别进入控制中心给每个栅栏配置规则后，一键整理才生效；如果用户没有预先配置规则，点击一键整理毫无反馈。

---

## 2. 目标设计方案

### 2.1 零摩擦秒建空白栅栏（彻底砍掉弹窗）
- **点击即创建**：点击控制中心「＋ 添加栅栏」，**不再弹出任何目录选择框**；
- **智能避让排布**：直接在屏幕空闲区域生成一个空白半透明玻璃栅栏，自动通过 `settle_move` 计算边界，绝不与已有栅栏重叠；
- **纯粹收纳属性**：默认 `storage_path = None`（纯粹桌面图标收纳盒），标题默认为「新栅栏 1/2...」，用户可自由拖入任意文件或就地重命名；
- **目录镜像降级为高级选配**：仅当用户未来确实需要让该栅栏与某个磁盘目录物理双向同步时，才在控制中心点击「更改位置…」，平时绝不打扰。

### 2.2 真正的「⚡ 一键全自动分类整理桌面」（零配置·自动建栏·秒级归位）
用户在桌面空白处右键、托盘右键或控制中心点击「⚡ 一键整理桌面」时：
1. **全盘图标智能分析**：
   扫描桌面上所有未归类图标（桌面源文件及未分组图标），根据扩展名与文件属性按 5 大核心类别聚类：
   - **常用应用**（.lnk, .exe, .url 等软件快捷方式）
   - **办公文档**（.docx, .xlsx, .pptx, .pdf, .txt, .md 等文档）
   - **图片媒体**（.png, .jpg, .gif, .mp4, .mp3 等图片与音视频）
   - **压缩文件**（.zip, .rar, .7z, .iso 等压缩包与镜像）
   - **文件目录**（普通文件夹）
2. **缺什么栅栏，自动建什么栅栏**：
   - 如果某个类别已有对应的规则栅栏，直接复用；
   - **如果某类别有文件、但桌面上尚未建立对应栅栏，系统自动在桌面上创建专属栅栏**（如「常用应用」、「办公文档」等），并排布在合适位置；
   - **按需生成**：若桌面上没有任何压缩包，则绝不生成多余的空压缩包栅栏，保持桌面极简；
3. **图标秒级归位**：
   将全部图标瞬间分发进入对应分类栅栏，未分类的特殊文件保留在桌面；
4. **完全可控**：
   整理后生成的栅栏具备完整的自由度，用户可随时拖动位置、重命名、更改风格或删除。

## 3. 详细改动清单

### 一、领域模型层（`crates/core/`）
- **[`crates/core/src/model.rs`](file:///g:/Codes/sylva/crates/core/src/model.rs)**：
  - 实现纯函数智能整理方法：
    ```rust
    #[derive(Debug, Clone, PartialEq, Eq)]
    pub struct AutoOrganizeReport {
        pub created_fences: usize,
        pub moved_icons: usize,
    }
    
    impl Desk {
        /// 全自动智能分类整理：扫描待整理图标，按需自动创建缺少的分类栅栏，并将图标分拣归位
        pub fn auto_organize_all(
            &mut self,
            source_fence_id: Option<u64>,
            screen_wa: Rect,
            scale: f32,
        ) -> AutoOrganizeReport;
    }
    ```
  - 编写零 Win32 依赖的独立单元测试，覆盖：
    - 桌面有应用、文档、图片时，自动补齐对应的 3 个新栅栏并将文件归入；
    - 桌面无某种类型时，不生成空栅栏；
    - 已有分类栅栏时优先复用，不重复建栏。

### 二、应用组装与交互层（`crates/app/`）
- **[`crates/app/src/main.rs`](file:///g:/Codes/sylva/crates/app/src/main.rs)**：
  - **重构 `ConsoleZone::AddFence`**：
    - 移除 `pick_folder`，点击直接生成 `storage_path: None` 的空白新栅栏，使用 `settle_move` 自动计算不重叠的合适位置，选中并持久化。
  - **升级 `ConsoleZone::AutoOrganize`**：
    - 接入 `desk.auto_organize_all`，调用屏幕工作区范围，一键完成智能建栏与全部分发，并触发场景重绘与持久化。
- **[`crates/app/src/context_menu.rs`](file:///g:/Codes/sylva/crates/app/src/context_menu.rs)**：
  - 栅栏右键菜单和托盘右键菜单的「⚡ 一键整理桌面」同样接入 `desk.auto_organize_all`。

## 4. 验证计划

1. **自动化单元测试**：
   ```powershell
   cargo test -p sylva-core
   cargo test --workspace
   ```
2. **静态检查与代码格式**：
   ```powershell
   cargo clippy --workspace -- -D warnings
   cargo fmt --all -- --check
   ```
3. **真实交互走查**：
   - 打开控制中心，多次点击「＋ 添加栅栏」，验证是否无需弹窗且栅栏秒级生成并不重叠；
   - 桌面放置若干快捷方式、txt/docx 文档、png 图片，点击「⚡ 一键整理桌面」；
   - 验证系统是否自动生成了「常用应用」、「办公文档」、「图片媒体」等栅栏并准确收纳对应图标；
   - 验证重启后 `desk.json` 配置完全正常保存与还原。
